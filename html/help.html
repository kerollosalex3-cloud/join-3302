How to use Join

Join is a Kanban board that helps you organize tasks by their current status. This guide explains how to use the features currently available.

1. Summary overview

The Summary gives you a quick overview of tasks. Its metrics represent open tasks, completed tasks, urgent tasks, and tasks in each board stage. The values shown in this project version are sample data.

2. View tasks on the board

Tasks are organized into four status columns: To do, In progress, Await feedback, and Done. Each card shows details such as its category, title, description, assignees, and priority.

  1. Enter a search term in Find Task to filter tasks by title or description.
  2. Select a task card to open its details, including the due date, priority, assignees, and subtasks.
  3. Close the details using the close icon or by clicking outside the dialog.

3. Navigation

Use the navigation to switch between Summary, Add Task, Board, and Contacts. On small screens, the navigation is located at the bottom of the page.

About this project version

In the current version, sample tasks on the board can be viewed and searched. Creating, editing, moving, or deleting tasks, as well as managing contacts, is not yet available. Add Task and Contacts are currently placeholders.
